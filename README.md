
# AgriMesh

## Fault-Tolerant Mesh Network for Precision Agriculture
### Rural Indian Landscapes

AgriMesh is a Python-based simulation demonstrating how
wireless mesh networks can support precision agriculture
in rural areas.

## Features
- Agricultural sensor network simulation
- Interactive wireless link failure controls
- Alternate-path routing using NetworkX
- Simulated soil moisture, temperature, and humidity
- Packet delivery performance metrics

## Technologies
- Python
- Streamlit
- NetworkX
- Pandas
- Matplotlib

## Run locally

Install dependencies:

    pip install -r requirements.txt

Start the dashboard:

    streamlit run app.py

**Note:** Sensor readings are simulated. This project
does not collect live agricultural sensor measurements.
